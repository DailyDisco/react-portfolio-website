# Technology marks

These selected SVGs are stored locally and used as decorative identification beside readable technology names. No icon font or remote icon request is used at runtime.

- Devicon SVGs are distributed under the included MIT license. Source: https://devicon.dev/ and https://github.com/devicons/devicon.
- Simple Icons SVGs are distributed under the included CC0 1.0 license. Source: https://github.com/simple-icons/simple-icons. Its upstream disclaimer is also included.
- `sources.json` records the exact upstream commit, file URL, hash, and collection for each unmodified SVG.
- Product names and logos belong to their respective owners. Their use identifies the technologies discussed and does not imply endorsement.

Unknown technologies use a decorative Lucide symbol from the application's existing dependency, with the technology name still visible.
